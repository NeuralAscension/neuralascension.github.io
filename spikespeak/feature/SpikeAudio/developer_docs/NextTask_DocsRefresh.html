In progress — documentation refresh (screenshots + prose)#

State: partly done. This file is the handoff; it is accurate as of 2026-08-21.

The GUI changed substantially on 2026-08-20/21 (two-row toolbar, collapsible column strips, OneBox ADC (SDR) / IO0..IO11 labelling, vertical one-line control strips, minimum widths). Most documentation screenshots and a good deal of prose still described the GUI that existed before that.

An 8-document audit produced a per-image specification — the claim each image supports, the exact GUI state needed to reproduce it, and the surrounding prose that is now factually wrong. This file records what has been actioned and what has not.

How to recapture#

tests/gui/_harness.py drives it. Set the source with the env var, and use the right display:

os.environ["SPIKESPEAK_GUI_SOURCE"] = "NPX 1.0 (OneBox)"   # or a Simulated … name
with Gui(monitor="landscape") as g:   # "portrait" for vertical shots
    g.live_view(settle=10); g.columns(3)

Traps that will otherwise waste a pass:

  • The Probe Map | Live Data tabs only appear when the source config's name: contains "NPX". SimNpx1.yaml is named "Simulated Data", so it shows no tab bar at all. Use an NPX-named source.
  • Play/Record have an in-flight PENDING state (dimmed, pulsing, disabled). Wait for it to settle or the button screenshot captures the wrong meaning.
  • Past 2 columns the strips auto-collapse, so a shot meant to show which band each column holds must pin them (document.querySelectorAll('.cc-pin').forEach(b => b.click())).
