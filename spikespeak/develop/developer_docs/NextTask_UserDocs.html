The capture tooling, and where it now lives#

The harness that produced the 2.0 tutorial's twenty-five dated stills was written in a session scratchpad, which does not survive the session. It has been copied to a durable location outside this repository, alongside the screen recorder built for the same job:

C:\Users\BIOEl\SpikesPeakRecorder\                 the click-to-run screen recorder
C:\Users\BIOEl\SpikesPeakRecorder\tutorial_capture\ the still/screencast harness + its README

It is deliberately not in the repo: it is an operator tool, it drives real hardware, and Contributing.md keeps working files out of the tree. Run it as

python tutorial_capture.py <path-to-repo> PXIe pxie_np1        # or: OneBox onebox_np2

It brings up its own backend and an isolated Chrome, writes user_docs/images/tut_<tag>_NN_<step>_<date>.png into the repo, and tears the rig down the safe way: pause, Disconnect, confirm deviceReady false, then quit. It never force-kills a backend with a probe open, which is the rule that costs a power-cycle to break.

What went wrong on the two attempts, so it does not happen a third time#

Both runs on 2026-09-02 connected, applied a cross-bank map and streamed correctly, then died in the same place.

  • Run 1 stopped at the channel pager, which had a range of zero. The column was on the NI-DAQ stream, which has eight channels and so never pages. Not a bug: see NextTask_LiveViewScrolling.md for why the range is legitimately zero, and note that the default layout on PXIe + NI-DAQ puts NI-DAQ in the second column.
  • Run 2 got a real pager range and then lost its Chrome connection when the front end was closed by hand mid-run.

Three fixes went into the harness afterwards and are in the copy above: every optional step is fenced so one failure costs a step rather than the whole rig session; set_columns waits for the column count before anything touches a column; and the pager step logs what the stream dropdown says against what the column actually draws. TUT_NOCAST=1 skips the screencast when only stills are wanted.
