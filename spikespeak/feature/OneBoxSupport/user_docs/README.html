SpikesPeak — User Guide#

How to run SpikesPeak and use the interface. SpikesPeak is a real-time neural acquisition app: a backend program serves a web UI that opens in your normal web browser, where you connect a probe, configure its channel map, and watch / record the live signal.

Quick start — 6 steps to streaming (and your first detection)#

No hardware needed — this uses a simulated source. (Full illustrated walkthroughs: GUI-Guide.md for connect → record, RippleDetection.md for the ripple module.)

  1. Launch. Run SpikesPeak.exe (or python run_spikespeak.py). Your browser opens at http://localhost:8234. (Details: Launching SpikesPeak.)
  2. Pick a source. Toolbar Source ▸ Simulated Data… → Neuropixels 1.0 — Ripple Detection (GUI). It connects with no probe attached.

3. Play. Press ▶, then open the Live Data tab — you'll see the live waveforms, one trace per channel, stacked by depth.

4. Open Ripple Detection. Click ◉ Ripple Detection in the toolbar; the dock slides in on the right. 5. Add a channel + arm. Drag an electrode label from the view (or type a number and Add), set Parameter-estimation time = 3 s (quick test), then press ▶ Start.

6. Watch it fire. After ~9 s the columns arm and detections start — the cowsay prints Ripple detected! The red STIM LED does not light on detection alone -- it lights only when the stimulation server acknowledges a real pulse. Stimulation is also opt-in: the dock's enable stimulation gate defaults OFF and the server must be armed, so a detection transmits nothing until you do both.

Launching SpikesPeak#

  1. Run SpikesPeak.exe. A console window opens (status/log messages) and your default web browser opens automatically to the UI (served locally at http://localhost:8234). - 📷 the console + the browser opening
  2. If the browser doesn't open, browse to http://localhost:8234 manually.
  3. Closing the browser tab quits the app (after a ~2-second grace, so a refresh is safe). You no longer need to close the console window separately.

Use the machine that has the PXI / probe hardware. Without hardware, choose Simulated Data or a synthetic source to explore the UI (those don't expose the probe channel-map panel).

The toolbar (left → right)#

📷 the toolbar

Control What it does
▶ / ⏸ Play Start / pause streaming. Disabled until a source is connected and the device is ready.
Window (sec) Width of the live time window (1 / 2 / 5 / 10 s).
Columns How many side-by-side chart columns to show (1–4; default 2).
Source Pick the input: NPX 1.0, NPX 2.0 Multishank (+ NI-DAQ / Synthetic Ripples variants), or Simulated Data. Selecting one connects it.
Disconnect Releases the current source and returns to "None".
⏺ Record Start / stop writing data to disk. Enabled only while playing.
Time Elapsed stream time.
Probe Map / Live Data (tabs) Switch between the channel-map editor and the live waveforms. Appears only for Neuropixels sources.
♪ (second row) Opens the spike audio monitor — listen to one channel through the speakers. Appears only for probe sources. See SpikeAudio.md.
Status box (far right) The latest action, color-coded: green = success, amber (pulsing) = working, red = error, gray = info. Hover for the full message + time.

The two views (Neuropixels sources)#

  • Probe Map — the channel-map (IMRO) editor: choose which electrodes record, then push the map to the probe. See the NP1.0 guide.
  • Live Data — the streaming waveforms, one trace per channel, depth-sorted. See the NP1.0 guide.

Current support#

Source / feature Status

Ripple detection + closed-loop stim ✅ SWR detection validated for NP1 + NP2 (simulation); ripple→UDP→stimulator closed loop verified, including a real hardware pulse. See RippleDetection.md -- Pi stim-server setup: ../raspberrypi_pulsegenerator/README.md.
Simulated sources ✅ Full hardware-free NP1 / NP2 / NI-DAQ / ripple / play-file sources for development. See SimulatedData.md.
Neuropixels OneBox ✅ Supported. Connect, stream, record and reconnect with NP1.0 or NP2.0 over USB3, plus the box's own 12-channel ADC in volts. source.npx.onebox is registered in src/core/Utils.cpp. Closed-loop ripple→stim runs on it at 0.92 ms (NP1.0) / 0.55 ms (NP2.0) with ASAP delivery — see RecordingTests/CLOSED_LOOP_LATENCY.md. The WavePlayer stim output works and is measured on DAC0 → breakout BNC IO0 (#49 closed 2026-08-24); its latency has not yet been compared against the Pi path. Operator walkthrough: OneBox-NPX2.md.
