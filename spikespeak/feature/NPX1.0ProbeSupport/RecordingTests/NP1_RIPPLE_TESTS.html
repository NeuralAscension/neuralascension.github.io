Neuropixels 1.0 — closed-loop ripple → stimulation results#

Real-hardware tests of the full closed loop: a synthetic sharp-wave ripple played into saline, detected online by SpikesPeak on a real NP1.0 probe, driving a single biphasic stimulus through the Raspberry Pi 3B+ / AM Systems 2300 stimulator, with the delivered pulse captured on NI-DAQ ai4.

Closed-loop latency = threshold crossing on the filtered signal → stimulus pulse observed on the NI-DAQ. Measured offline, pulse-anchored on the shared Neuropixels clock. Full method, the delivery-mode comparison and the figures: Closed-Loop Latency.

Configuration#
Probe / config Neuropixels 1.0, NPX 1.0 with NI-DAQ (default) or NPX 1.0 with NI-DAQ (ASAP)
Detector input native 2.5 kHz data.npx.lfp, int16, decimation 1
Threshold mean + 2.5 σ on the ripple envelope (150–250 Hz FIR → abs → envelope FIR)
Lockout 200 ms
Stimulus one biphasic pulse per detection (60 µs phase, 10 µs gap) on ai4
NI-DAQ PXI-6133, 40 kHz (25 µs edge resolution)

Every test: 0 unmatched — every delivered stimulus pairs with a preceding detection, and every detection that armed the stimulator produced a pulse.

Latency is independent of quorum size, in both delivery modes:

quorum default ASAP saving
1 ch 1.483 ms 0.977 ms −506 µs (−34.1 %)
2 ch, quorum 2 1.489 ms 0.942 ms −547 µs (−36.7 %)
4 ch, quorum 3-of-4 1.484 ms 0.963 ms −521 µs (−35.1 %)

Flat within 6 µs across quorum in the default mode and within 35 µs with ASAP. Quorum determines which threshold crossing triggers the stimulus, not the delay from that crossing to the pulse.

ASAP delivery is sub-millisecond in every configuration, and the saving reproduces at every quorum level, with the interquartile range 4–5× tighter. Paired figures: Closed-Loop Latency.

Online-detection counts exceed the recorded pulse count because detection begins before the recording starts (during baseline settling) and continues through the post-record settling window; only pulses inside the recording are analysed.

Electrodes are auto-picked per run (strongest ripple), so paired conditions are not electrode-matched — see the measurement notes in Closed-Loop Latency.

Probe parity#

Neuropixels 2.0 runs the same closed loop at 1.17–1.18 ms with default delivery — about 0.3 ms faster than NP1.0, consistent with its finer pre-decimation delivery granularity. See NP2_RIPPLE_TESTS.md.

Reproduce#

python ripple_tools/run_latency_hw.py --source "NPX 1.0 with NI-DAQ (ASAP)" \
    --dir <abs recdir> --name <name> --nchan 2 --quorum 2 --n 1000
python ripple_tools/analyze_recording.py <recdir> --ws <recdir>/<name>_ws.jsonl --figs <recdir>/analysis

Recording directories hold the raw .bin bands + sidecars and are not version-controlled; the analysis/ figures and _summary.json are.
